# DoH-Switcher // CyberDNS v2.0.4

Легковесное расширение (Manifest V3) для браузеров Google Chrome, Edge и Chromium для мгновенного управления и переключения между DNS-over-HTTPS (DoH) серверами в один клик с встроенной RFC 8484 диагностикой, многоуровневой защитой и кибер-терминалом событий.

---

## ⚡ Ключевые возможности

- **Мгновенное переключение без перезагрузки браузера**:
  - Нативный вызов Windows API `userenv.dll` (`RefreshPolicyEx` / `RefreshPolicy`) и широковещательный сигнал `WM_SETTINGCHANGE`.
  - Браузер динамически считывает новые правила реестра на лету.
- **Многоэтапный цикл подключения и безопасный Rollback**:
  - `CONNECTING` — применение настроек через Native Host и очистка кэша резолвера.
  - `VERIFYING` — отправка единичного тестового DNS-зонда RFC 8484 к выбранному эндпоинту.
  - `CONNECTED` — подтверждённое рабочее соединение (зелёный индикатор `#00FFA3`).
  - `ROLLBACK` — автоматический откат к предыдущему рабочему состоянию при любых сбоях или ошибках хоста.
- **Реальная диагностика DNS (RFC 8484 + RFC 1035)**:
  - Парсинг бинарных DNS-пакетов wire-формата: валидация Transaction ID, QR-бита ответа, OpCode, RCode (отсутствие ошибок DNS), проверка секций Questions и Answers.
  - Измерение фактического RTT (в миллисекундах) через эндпоинт `application/dns-message`.
  - Проверка статуса доступности (`ONLINE` / `OFFLINE` / `TIMEOUT`) только по требованию пользователя, без скрытых фоновых запросов.
- **Строгая безопасность (Strict HTTPS Only)**:
  - Полный запрет незашифрованного HTTP (`http://`) на всех уровнях: в форме ввода, при импорте JSON и в Native Host.
  - Ограничение размера пакета Native Messaging до 16 КБ для защиты от переполнения памяти.
  - Строгий whitelist допустимых команд (`SET_DOH`) и режимов (`secure`, `off`, `automatic`).
  - Глубокая санитаризация URI и удаление фантомных записей реестра.
- **Модульная чистая архитектура (ES Modules)**:
  - Фронтенд разбит на независимые нативные ES-модули без тяжелых сборщиков (Webpack/Vite):
    - `js/dns-core.js` — парсер бинарных пакетов RFC 8484 и зондирование сети.
    - `js/native-client.js` — клиент взаимодействия с Native Host на промисах.
    - `js/storage.js` — работа с `chrome.storage` и безопасный импорт/экспорт JSON.
    - `js/ui.js` — киберпанк HUD, карточки серверов, терминал и тосты.
    - `js/constants.js` — реестр пресетов и состояний.
    - `popup.js` — чистый контроллер состояний и событий.
- **Cyber Terminal & Event Log**:
  - Журнал системных событий в реальном времени (`SWITCH`, `NATIVE`, `DIAG`, `FAV`, `INJECT`).
  - Экспорт и импорт пользовательских серверов в JSON с автоматической валидацией.

## 🚀 Установка

1. Скачайте исходный код или распакуйте готовый архив релиза из папки `dist/`.
2. В браузере (Chrome / Edge / Brave) откройте страницу расширений: `chrome://extensions/`.
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку `DoH-Switcher`.
5. Запустите файл **`install-host.bat`** (он запросит права администратора для разблокировки записи политик HKLM стандартным пользователям).

## 🛠️ Системные скрипты

### Активация нативного движка: `install-host.bat`
- Автоматически запрашивает права администратора (UAC).
- Генерирует корректный `com.doh.switcher.json` с абсолютным путём к `doh-host.exe` на вашем ПК.
- Регистрирует Native Messaging Host в Chrome и Edge.
- Предоставляет права записи для группы `Users` (`S-1-5-32-545`) на ключ `HKLM\Software\Policies\Google\Chrome`, благодаря чему расширение переключает DoH в 1 клик без постоянных запросов UAC.

### Очистка политик: `clear-policy.bat`
Применение политик через реестр сопровождается системным статусом *«Браузером управляет ваша организация»*.  
Если вы хотите полностью удалить политики DoH и вернуть браузер в заводское состояние:
1. Запустите файл **`clear-policy.bat`** от имени администратора.
2. Перезапустите Chrome — плашка управления полностью исчезнет.

## 📦 Сборка релиза

Для сборки автономного дистрибутива запустите:
```bash
node package.js
```
Скрипт автоматически:
- Санитизирует `com.doh.switcher.json` (удаляет локальные пути пользователя).
- Упаковывает модули `js/`, иконки, батники и бинарники.
- Создает чистый релизный архив в `dist/DoH-Switcher-v2.0.4.zip`.
